# Third-party data

## CiP Discrete Manufacturing Dataset

This repository includes a metadata and quality-table subset of the
**CiP Discrete Manufacturing Dataset**, created by the Institute of Production
Management, Technology and Machine Tools (PTW), TU Darmstadt.

- Source: https://zenodo.org/records/10118474
- DOI: https://doi.org/10.5281/zenodo.10118474
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Included subset: metadata JSON, quality CSV, production logs and dataset
  documentation
- Excluded: large HDF5 process and sensor signals

The original creators retain attribution for the dataset. Project code and
derived evaluation artifacts are separate from the third-party dataset.
