# 8단계 — 프로젝트 스키마 기반 Text-to-Cypher

활성 프로젝트를 바꾸면 API 서비스 번들을 다시 구성해 해당 프로젝트의 versioned schema를 LLM에 주입한다.

- 생성·자기수정 모두 같은 프로젝트 schema context를 사용한다.
- CiP-DMD 전용 의미 검증 규칙은 다른 도메인에 잘못 적용하지 않는다.
- 일반 프로젝트 쿼리는 `project_id` 범위를 포함하지 않으면 EXPLAIN/실행 전에 차단한다.
- 프로젝트별 Gold 예제 파일이 있으면 자동 사용하고, 없으면 공통 예제로 폴백한다.

따라서 UI의 프로젝트 전환은 단순 화면 필터가 아니라 생성·검증·실행 컨텍스트 전체를 전환한다.
