# 발표용 데이터·모델 제한사항

- CiP-DMD에는 설비 호기와 소모품 교체 이력이 없어 제품 구성품·공정
  anomaly·품질 관계를 이용한 **RCA 후보 탐색**으로 범위를 제한한다.
- 완제품 802개 중 구성품 두 개가 모두 연결된 제품은 767개(95.6%)이며,
  불완전 35개는 누락 사실을 숨기지 않는다.
- anomaly class에 원본이 제공하지 않은 물리적 고장명을 붙이지 않는다.
- 그래프 경로는 상관·추적 근거이며 물리적 인과관계를 확정하지 않는다.
- Gemini 26문항 고정-seed 회귀 평가의 의미값 정확도는 61.5%,
  컬럼 이름까지 같은 엄격 계약 정확도는 38.5%다. 실행 성공률 100%와
  결과 정확도를 같은 의미로 설명하지 않는다.
- 의도적 오류 8건의 자기수정은 검증 통과 100%였지만 정답값 회복은
  37.5%였다. 문법 수정과 업무 의미 회복을 같은 능력으로 설명하지 않는다.
- 최초 Blind 실행 후 의미 검증을 보완했으므로 최신 수치는 회귀 측정이다.
  외부 일반화 성능에는 별도의 신규 holdout이 필요하다.
